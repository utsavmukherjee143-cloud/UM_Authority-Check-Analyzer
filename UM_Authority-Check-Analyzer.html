Operational Guidebook
Complete operating procedures for UM_Authority-Check-Analyzer
1. Purpose of the Tool
UM_Authority-Check-Analyzer is an IBM-developed SAP security intelligence platform that identifies weak, missing, misplaced, or ineffective authorization checks in SAP ABAP code, T-Codes, Fiori applications, Web Dynpro applications, and OData services. It provides evidence-based findings, corrected code recommendations, and structured audit evidence — all requiring human review before any SAP system change.
This tool is read-only and diagnostic. It never modifies SAP systems automatically.
2. Intended Users
  • SAP Security Architects and Consultants
  • SAP Basis and Security Administrators
  • ABAP Developers performing security reviews
  • Internal and External Auditors
  • GRC and Compliance teams
  • SAP Project Security Leads

    4. How to Scan ABAP Code
    Step 1 — Open the ABAP Code Scanner
    Click ABAP Code Scanner in the left navigation sidebar.
    Step 2 — Configure the Scan
  • Select the SAP System Type (e.g. S/4HANA On-Premise)
  • Select the SAP Release (e.g. 2023 FPS02)
  • Enter the Transaction Code or Program name if known
  • Select the Analysis Mode (Full Analysis recommended)
    • Step 3 — Load the ABAP Code
  • Paste ABAP source code directly into the text area, or
  • Click the upload zone and select a .abap or .txt file, or
  • Drag and drop a file onto the upload zone
    • Step 4 — Run Analysis
    Click ▶ Run Analysis. The engine scans the code and displays findings within seconds. Each finding includes: Finding ID, Rule ID, Severity, Line Number, Statement, Authorization Object, Risk, Corrected Code, and Before/After comparison.
    Never paste code containing passwords, encryption keys, or personal data. The scanner masks common credential patterns automatically.
    5. How to Interpret Findings
  • CRITICAL / HIGH: Confirmed security weakness. Immediate review required. Corrected code is provided.
  • MEDIUM: Probable weakness. Review recommended. Context-dependent.
  • LOW / INFO: Potential weakness or observation. Manual review recommended.
  • PASS: Authorization check is correctly implemented for the detected pattern.
  • Manual Review Required: Dynamic objects, complex logic, or insufficient static evidence. Requires STAUTHTRACE or human expert review.
    • 6. How to Use SU53 and STAUTHTRACE Evidence
    Navigate to SU24/SU25 Analysis → SU53 / STAUTHTRACE. Paste the output from transaction SU53 (authorization check failure display) or a STAUTHTRACE export. The interpreter identifies the missing authorization object, field, and value, and maps it to a required SU24 proposal entry or PFCG role correction.
    7. How to Export Audit Evidence
    Navigate to Audit Evidence → Export Options. Choose CSV, JSON, or HTML format. The full package includes all findings, corrected code, timestamps, confidence levels, and approval status. All exports are session-scoped and do not persist to any external server.
    8. How to Manage False Positives
    Each finding has a Mark as False Positive option. This requires a justification comment. False positives are included in the audit trail with the reviewer's identity and timestamp. They do not disappear — they are reclassified.
    9. Troubleshooting
  • Scan produces no results: Ensure ABAP code contains at least one function module call, database operation, or AUTHORITY-CHECK statement.
  • Dynamic object warning: The scanner cannot resolve dynamically constructed authorization object names at static analysis time. Use STAUTHTRACE to capture runtime data.
  • Wrong SAP release selected: Some rules are version-specific. Select the correct release for accurate results.
  • Export fails: Ensure the browser allows file downloads from this application.

    Business Problem Addressed
    SAP authorization vulnerabilities — missing, weak, or misplaced AUTHORITY-CHECK statements — are among the most exploited security weaknesses in enterprise SAP landscapes. Manual code review is time-consuming, inconsistent, and error-prone. UM_Authority-Check-Analyzer provides automated, evidence-based, version-aware detection with corrected code recommendations, enabling security teams to identify and remediate authorization gaps at scale.

    This tool is for authorized IBM and client security professionals only. Findings are diagnostic and require human expert review.     Security & Compliance Principles
    Evidence-Based
    Every finding cites the exact source code statement, line number, and detection rule. Inferred values are clearly labelled and distinguished from confirmed findings.
    Human-in-the-Loop
    No automated SAP system changes. Every correction requires review and approval by a qualified SAP Security professional. The tool assists — it does not replace — human judgment.
    Clean Core Aligned
    All remediation recommendations follow SAP Clean Core principles: released APIs, extension points, no standard table modifications, upgrade-stable patterns.
