What It Does

UM_Authority-Check-Analyzer is a browser-only IBM enterprise tool that automates SAP authorization security analysis across ABAP code, T-Codes, Fiori apps, Web Dynpro components, OData services, and SU24/SU25 proposals. It detects missing, weak, or misplaced AUTHORITY-CHECK statements; proposes corrected ABAP patterns; scores authorization coverage; and produces audit-ready evidence packages — all without connecting to any live SAP system.

Architecture

Deployment

  • Single HTML file — no build step, no server
  • Companion tcode-db.js (10.1 MB, 80,802 T-Codes)

  • Method Inventory — call graph, per-method detail
  • Coverage Matrix — colour-coded operation x entity grid

  • Test Planner — auto-generated positive + negative cases
  • Remediation — corrected ABAP patterns, approval workflow
  • Reports — 7 export types (HTML, CSV, JSON, TXT)

15 AUTH-COV Rules

  • CRITICAL — Missing check in CREATE / UPDATE / DELETE / EXECUTE
  • HIGH — Missing check in READ_ENTITY / GET_ENTITYSET
  • HIGH — SY-SUBRC not evaluated after check
  • HIGH — Auth check after database SELECT (post-read)
  • HIGH — $batch method unprotected
  • MEDIUM — Helper delegation without return verification
  • MEDIUM — Mass-read bypasses per-record authorization
  • MEDIUM — Hardcoded authorization value
  • MEDIUM — Missing BYPASS_BUFFER on SELECT SINGLE
  • MEDIUM — EXPAND method unprotected
  • LOW — Dynamic auth object (cannot verify statically)
